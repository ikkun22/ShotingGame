# シューティングゲーム 説明書

## 1. ゲーム概要

このゲームは、プレイヤーが画面上を動きながら敵を倒し、ボスを撃破してステージを進んでいく2Dシューティングゲームです。

- 画面サイズ: 800 x 600
- 進行形式: タイトル → ステージ選択 → ゲーム本編 → ゲームオーバー → ハイスコア登録
- 目的: 敵を倒してスコアを稼ぎ、ボスを破壊して次のステージへ進む
- 難易度: 敵の種類やボス攻撃がステージごとに変化

---

## 2. 実行方法

### そのまま起動する場合

ゲームのフォルダ内で次を実行します。

```bash
cd "C:\GameFile"
python main.py
```

または、同じフォルダ内で次も起動可能です。

```bash
python shotingGameEX.py
```

### 必要環境

- Python 3.x
- pygame がインストール済みであること

もし pygame が入っていない場合は、以下のようにインストールします。

```bash
pip install pygame
```

## 3. ゲームの流れ

### タイトル画面

- START: ゲームを開始する
- CUSTOM: 速度などの設定を変更する
- SCORE: ステージごとのハイスコアを見る
- EXIT: ゲームを終了する

メニュー選択は、弾をボタンに当てる方式になっています。

### ステージ選択

- ステージ1〜3から選択
- ステージごとに敵の種類やボスの挙動が変わる

### ゲーム本編

- プレイヤーは自機として画面内を移動する
- 敵が接近してくるので、弾で倒す
- 敵を倒すとスコアが加算され、アイテムが落ちることがある
- 一定数の敵を倒すとボス戦が始まる
- ボスを倒すと次のステージへ進みやすくなる

---

## 4. 操作方法

### 基本操作

- 左右: 矢印キーまたは A / D
- 上下: 矢印キーまたは W / S
- 射撃: スペースキー
- チャージ射撃: スペースを長押ししてから離す
  - 通常弾とチャージ弾の両方がある
  - しばらく長押しすると強力な弾になる
- ポーズ: Enterキー

### メニュー操作

- タイトル画面やステージ画面では、弾をボタンに当てて選択する
- 画面上の「START」「EXIT」「CUSTOM」などを狙って撃つ

---

## 5. プレイヤーの特徴

### 自機

- 画面下部に配置される三角形の自機
- 画面外には出られない
- 最大HPは 5
- 被弾すると一定時間無敵状態になる

### 無敵・点滅

- 被弾直後は一瞬だけ点滅し、連続ダメージを防ぐ
- 発生中はプレイヤーが一瞬見えなくなることがある

---

## 6. 敵の種類

ゲーム中の敵にはいくつかのタイプがあります。

### 1. chaser
- プレイヤーに向かって追いかけてくる
- 近づくと危険

### 2. straight
- その場から下にまっすぐ進む
- シンプルで見切りやすい

### 3. zigzag
- 左右にゆらぎながら下に進む
- 位置を読んで避ける必要がある

### 4. horizontal
- 左右に横移動しながら下降する
- 画面端で反転する

### 5. diving
- プレイヤーの方向に横へ寄りながら落ちてくる
- 予測しづらい

### 6. splitter
- 画面を横に動きながら降ってくる
- 倒すと小さな分裂敵を作ることがある

---

## 7. ボス戦

一定数の敵を倒すとボスが出現します。

- ボスは大きい敵として画面上部に出現する
- 横に往復しながら攻撃してくる
- 一定間隔で弾を発射する
- ステージごとに攻撃パターンが変化する
- ボスのHPが0になると撃破

### ボスの特徴

- ステージ2では反射弾などの特殊攻撃が増える
- ボス撃破後、次のボスではHPが上がることがある
- 画面上の敵を倒してからの時間経過で再出現する流れが続く

---

## 8. アイテム

敵を倒したときやボス撃破時に、アイテムが落ちることがあります。

### アイテムの種類

- shield
  - 1回だけダメージを防ぐ
  - 「★」の形のアイテム

- spread
  - 弾の方向が増える
  - 連続で取ると3方向、5方向に発展する
  - 「￥」の形のアイテム

- heal
  - HPを回復する
  - 「❤」の形のアイテム

### 取得方法

- 自機がアイテムに触れると効果が発動する
- 回復アイテムはHPが最大のときは残ることがある

---

## 9. スコアとハイスコア

- 敵を倒すとスコアが加算される
- ボスを倒すとさらに大きく増える
- ゲームオーバー時にハイスコア登録の対象になる
- ハイスコア時は、名前を入力して登録する
- 入力できる名前は最大4文字で、ランキングに表示される
- ステージごとにランキングが保存される

保存先: `GameFile/high_scores.json`

### ハイスコアをリセットする方法

ハイスコアを初期化したいときは、次の手順で実行します。

```bash
cd "C:\GameFile"
python reset_scores.py
```

実行すると、ステージ1〜3のランキングがすべて空に戻ります。

または、保存ファイルを直接削除・編集してもリセットできます。

```text
GameFile/high_scores.json
```

このファイルを削除した後に、ゲームを起動すると自動で空のランキングとして再生成されます。

## 10. カスタム設定

タイトル画面の CUSTOM からさまざまな設定を変更できます。

- 敵の速度
- 弾の速度
- プレイヤー速度
- 色反転設定
- 初期設定へのリセット

変更した値はそのままゲーム中に反映される。

## 11. 主要ファイルの役割

- `main.py`: ゲームの起動入口
- `shotingGameEX.py`: ゲーム本体の実装
- `entities.py`: 敵やアイテム、弾の生成処理
- `game.py`: 敵移動やボス弾のロジック
- `stages.py`: ステージごとの設定
- `settings.py`: 全体設定値
- `audio.py`: 効果音の生成と再生
- `ui.py`: メニュー画面や描画処理
- `scores.py`: ハイスコアの保存と読み込み

---

## 12. ゲームを上手く進めるコツ

- 最初は敵の動きのパターンを覚える
- 画面の端で反転する敵や横に揺れる敵は、動きを見て避ける
- HPが少ないときは回復アイテムを優先して拾う
- 敵が大量に来たら、チャージ弾で一気に処理するのが有効
- ボス戦では、接近しすぎると被弾しやすいので距離を保つ
- 難しすぎると感じたら、CUSTOM画面で敵の速度や弾の速度、プレイヤー速度を下げて難易度を調整する
- 特に初めて遊ぶときは、敵の速度と弾の速度を落としてから慣れてきたら元の値に戻すと進めやすい

---

## 13. まとめ

このゲームは、単純な弾幕ゲームではなく、敵の種類やボスの攻撃パターン、アイテムの効果、ハイスコア要素を組み合わせた「進行型シューティングゲーム」です。

慣れるまでは敵の動きに戸惑うかもしれませんが、ステージごとに変わる攻撃とリズムを覚えることで、だんだん上達していきます。
