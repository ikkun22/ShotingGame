BatteryShoting 仕様書
====================

1. 概要
--------
BatteryShotingは、プレイヤー機を操作して敵やボスを撃破する2Dシューティングゲームである。
ゲーム開始時に取得したバッテリー残量を、プレイヤーの最大HPと最大スタミナに反映する。
画面サイズは800 x 600ピクセル。

2. 動作環境と起動
------------------
- Python 3とpygameを使用する。
- WindowsではWindows APIからバッテリー残量を取得する。
- バッテリー情報が取得できない環境でもプレイできる。その場合は最大HP 5、最大スタミナ50で開始する。
- ゲームフォルダーを移動するときは、GameFileフォルダーと、その中のsoundsフォルダーを一緒に移動する。
- GameFileフォルダーで次のコマンドを実行して起動する。

    python main.py

- ゲーム本体を直接起動する場合は次を実行する。

    python BatteryShoting.py

- 起動入口はmain.py、ゲーム本体はBatteryShoting.pyである。
- 操作はキーボードを前提とする。タッチ操作には対応していない。

3. 画面遷移
------------
1) 起動するとタイトル画面を表示し、メニューBGMを再生する。
2) タイトル画面のSTARTを選ぶとステージ選択画面を表示する。
3) ステージ1～3のいずれかを選ぶと、バッテリー残量を読み込み、プレイヤーなどのゲーム状態を初期化する。
4) ゲーム開始前に、HPとスタミナを0から1ずつ増やす演出を中央に表示する。この間はBGMを再生しない。
5) 演出完了後にゲーム中BGMを再生し、ゲーム本編を開始する。
6) ゲーム中にEnterキーを押すとポーズ画面を表示する。ゲームを続けるかタイトルへ戻るかを選択する。
7) HPが0になるとゲームオーバーになり、画面中央に最終スコアを表示する。
8) ゲームオーバーから5秒後、スコアがランキング登録対象なら名前入力画面を表示する。その後タイトル画面へ戻る。
9) ゲーム終了時はEXITを選択する。

タイトル画面のメニューはSTART、EXIT、CUSTOM、SCOREで構成する。
メニュー項目はプレイヤーの弾を当てて選択する。
ウィンドウを閉じる操作でもゲームを終了する。

CUSTOM画面では、設定項目の左右矢印に弾を当てて値を変更する。
- 敵の速度: 0.5～10.0、0.5刻み。初期値は1.0。
- 弾の速度: 2～20、2刻み。初期値は10。
- プレイヤーの速度: 1.0～10.0、0.5刻み。初期値は3.0。
- 色反転: ボタンに弾を当てるたびにON/OFFを切り替える。
- 初期設定に戻す: 速度と色反転を初期値に戻す。
- タイトルへ戻る: タイトル画面へ戻る。

4. 操作
--------
ゲーム中:
- 矢印キー: プレイヤーを上下左右に移動する。画面外には移動できない。
- Spaceキーを押して離す: 射撃する。押している時間で通常弾かチャージ弾かを決める。
- Spaceキーを1秒以上押して離す: チャージショットを発射する。
- Cキー: スタミナを消費して回避する。
- Enterキー: ポーズ画面を開く。
- ポーズ画面: 上下キーで項目を選び、Enterキーで決定する。

メニュー:
- 矢印キーでプレイヤーを移動し、Spaceキーで弾を発射する。
- 弾をボタン、ステージ、設定変更用の矢印に当てて選択する。
- SCORE画面ではステージ別ランキングを切り替え、BACKに弾を当てて戻る。
- ハイスコア名前入力では最大4文字を入力し、Backspaceで1文字削除、Enterキーで登録する。

5. バッテリー、HP、スタミナ
----------------------------
ゲーム開始時にバッテリー残量を読み取り、最大HPと最大スタミナを設定する。
タイトルへ戻って次のゲームを始めるときは残量を再取得する。

- 最大HP: バッテリー残量を10で割って四捨五入する。最低値は1。
- 最大スタミナ: バッテリー残量と同じ数値（0～100）。
- 残量を取得できない場合: 最大HP 5、最大スタミナ50。
- ゲーム中のHPは最大HPから開始する。HPが0になるとゲームオーバー。
- HPは画面左上の赤いゲージ、スタミナはその下の緑のゲージに表示する。
- ゲージの横に現在値と最大値を数値で表示する。
- ゲーム開始時のカウントアップは約25ミリ秒ごとに値を1ずつ増やす。最大値到達後、約0.5秒表示してから開始する。
- スタミナが1増えるたびにカウントアップ音を再生する。

スタミナ消費:
- 通常射撃: 15
- チャージショット: 30
- 回避: 10
- スタミナが0の場合は射撃と回避を開始できない。
- 行動開始時にスタミナが消費量未満でも、残っている分を消費して0にする。
- 射撃または回避の後、500ミリ秒経過してから回復を開始する。
- 28ミリ秒ごとに1回復し、最大スタミナを超えない。

画面右下のバッテリー表示は約1秒ごとに更新する。残量不明の場合は「--%」と表示する。
ゲーム画面には左上にHP・スタミナ、左下にスコア、右上にステージ番号を表示する。
ボス戦中は画面下部にボスHPとゲージを表示する。

6. 戦闘ルール
--------------
プレイヤー:
- 初期位置は画面中央下部。通常の移動速度は1フレームあたり3ピクセル。
- 通常射撃は上方向へ弾を撃つ。
- チャージ射撃はSpaceキーを1秒以上押し続けてから離すと発射する。
- チャージ中はプレイヤーの前方にチャージ表示を描く。チャージ中にポーズを開くとチャージを解除する。
- 射撃時にスタミナを消費できた場合のみ弾を発射する。
- プレイヤーの弾は通常敵を攻撃する。チャージ弾は敵に当たった後も残り、複数の敵に当たる場合がある。

被弾:
- 通常敵との接触、ボス弾または反射弾との接触で被弾する。
- 被弾するとHPが1減り、約1秒間、次の被弾を受けない。通常の無敵時間中はプレイヤーが点滅する。
- シールド所持中は次の被弾によるHP減少を防ぎ、シールドを消費する。

回避:
- Cキーを押し、スタミナを消費できた場合に回避を開始する。
- 回避中は0.5秒間無敵となり、プレイヤーを水色で表示する。
- 被弾後の無敵時間中、または回避中は回避を開始できない。
- 回避が成立したときに回避音を再生する。

敵:
- 初期の通常敵数は5体。通常敵を倒すか画面下へ通過させると補充する。
- 通常敵を倒すとスコアが1増える。敵との接触で敵が除去された場合もスコアと撃破数に加算する。敵が画面下へ通過しただけではスコアは増えない。
- 敵の種類はchaser（追跡）、straight（直進下降）、zigzag（左右に揺れながら下降）、horizontal（横移動しながら下降）、diving（プレイヤー方向へ寄りながら急降下）、splitter（横移動しながら下降）。
- splitterを倒すと小型の2体に分裂する場合がある。分裂した小型敵は次の敵補充数には数えない。

7. ステージとボス
------------------
各ステージは敵を50体倒すとボス戦を開始する。ボス戦開始時に通常敵と画面上の敵弾を消去する。

- ステージ1: chaser、straight、zigzagが出現する。ボスは通常弾を複数方向に発射する。ボスを倒すたび、次回以降の発射間隔を短縮する（最短300ミリ秒）。
- ステージ2: horizontal、diving、splitterが出現する。ボスは通常の拡散弾を使わず、画面端で反射する弾を約1秒ごとに発射する。ボスHPが半分以下になると、狙い方向の左右にも弾を分ける。
- ステージ3: 6種類すべての敵が出現する。ボスは通常の拡散弾を発射し、被弾時にプレイヤー方向へ反射弾を撃つ。
- ボスは画面上部を左右に移動する。ボスのHPは画面下部のゲージに表示する。
- ボスに弾が当たるとHPが1減り、短い無敵時間（約120ミリ秒）が発生する。ボスにダメージを与えるごとにスコアが1増える。
- 初回ボスHPは10。撃破後は次のボスHPを2倍にし、次回ボスまでに必要な撃破数を10増やす。
- ボス撃破時に回復アイテムを落とす。3秒後に通常敵を再出現させる。ボス撃破後は通常敵の編成数を1体増やす。

8. アイテム
------------
通常敵を倒すと5%の確率でアイテムを1つ落とす。アイテムは下方向へ移動し、プレイヤーと接触すると取得する。

- シールド（★）: 次の被弾によるHP減少を1回防ぐ。
- 回復（ハート）: HPを1回復する。HPが最大のときは取得できず、画面に残る。
- 拡散（￥）: 射撃を3方向、さらに5方向へ強化する。最大強化後に取得してもレベルは上がらない。
- アイテム取得時はアイテム獲得音を再生する。

9. スコアとランキング
----------------------
- 通常敵の撃破（プレイヤーとの接触で除去された場合を含む）と、ボスへの有効な攻撃1回ごとにスコアを1加算する。
- ランキングはステージ別に保存し、各ステージ上位10件を表示する。
- 10件未満の場合は登録対象。10件登録済みの場合は10位と同点以上のスコアが登録対象。
- 登録対象の場合、ゲームオーバー後に最大4文字の名前を入力して登録する。
- データはGameFile/high_scores.jsonに保存する。
- ランキング初期化はGameFileフォルダーで次を実行する。

    python reset_scores.py

この操作はステージ1～3のランキングデータを空にする。

10. 音声
---------
- MP3ファイルはGameFile/soundsフォルダーに保存する。ゲームを移動するときはこのフォルダーも一緒に移動する。
- メニューでは「ゲーム待機中BGM.mp3」、ゲーム本編では「ゲーム中BGM.mp3」をループ再生する。
- HP・スタミナの開始演出中はBGMを停止する。演出後にゲーム中BGMを開始する。
- ゲーム終了後にタイトルへ戻るとメニューBGMへ切り替える。
- 射撃、チャージ、チャージショット、プレイヤー被弾、敵への攻撃、回避、アイテム取得、最終スコア表示、メニュー決定・キャンセルなどの効果音を再生する。
- 効果音の個別音量はaudio.pyのSFX_VOLUMES、BGM音量はMUSIC_VOLUMESで設定する。値の範囲は0.0（無音）～1.0（最大）。

11. 主なファイル
-----------------
- main.py: ゲーム起動入口。
- BatteryShoting.py: メニュー、ゲーム進行、戦闘、画面遷移。
- Battery.py: Windowsバッテリー残量取得と最大HP・スタミナ計算。
- settings.py: 画面、プレイヤー、敵、ボス、スタミナなどの基本設定。
- stages.py: ステージ別の敵編成とボス設定。
- entities.py: 敵、弾、アイテムの生成と分裂処理。
- game.py: 敵とボス反射弾の移動処理。
- ui.py: ゲージ、メニュー、ランキングなどの描画。
- audio.py: 効果音・BGMの読み込み、再生、音量設定。
- scores.py: ランキングの読み込み、判定、保存。
- reset_scores.py: ステージ別ランキングの初期化。
- high_scores.json: ランキング保存データ。
- sounds/: 効果音とBGMのMP3ファイル。

12. shotingGameEXとの比較
--------------------------
引き継いだ主な機能:
- ステージ選択、CUSTOM設定、ランキング画面。
- 追跡型・直進型・ジグザグ型などの敵、敵の補充、分裂型の敵。
- 50体撃破後のボス戦、ステージごとに異なる敵編成とボス攻撃。
- シールド・回復・拡散アイテム、スコア、ステージ別ランキング。
- 移動速度・弾速・敵速度のカスタマイズと色反転。
- ステージ設定、敵・弾の生成、移動処理、ランキング処理の基本実装は共通。

BatteryShotingで追加した機能:
- Windowsのバッテリー残量を取得し、最大HPと最大スタミナに反映する。
- バッテリー残量が不明な場合の初期値（HP 5、スタミナ50）。
- スタミナの消費、時間経過による回復、残量がない場合の射撃・回避制限。
- Cキーによる回避。スタミナを消費して0.5秒間無敵になり、プレイヤーを水色で表示する。
- ゲーム開始時、HPとスタミナを中央で0から1ずつ増やして表示する演出。
- 画面右下のバッテリー表示、左上のHP・スタミナゲージ。
- メニューBGMとゲーム中BGMの切り替え。開始時の演出中はBGMを停止する。
- 射撃・チャージ・チャージショット、プレイヤー被弾、敵への攻撃、回避、アイテム取得、最終スコア表示、メニュー操作などの個別効果音。
- 効果音とBGMの個別音量設定。

変更した点:
- タイトル・アプリ名を「ShotingGameEX」／「2D Shooting」から「BatteryShoting」に変更。
- HPを固定値5からバッテリー残量連動に変更。ゲーム中のHP表示も、画面右下の数値表示から左上の赤いゲージと現在値表示に変更。
- 通常射撃・チャージ射撃にスタミナ消費を追加。チャージ時間は1秒のまま。
- メニューやゲーム中の合成効果音を、soundsフォルダー内のMP3を使った音声とBGMへ拡張・置換。BGMはメニューとゲーム本編で別の曲を使う。
- MP3をsoundsフォルダーへまとめ、audio.pyの場所を基準に読み込む構成に変更。ゲームフォルダーを移動する場合はsoundsフォルダーも一緒に移動する。
