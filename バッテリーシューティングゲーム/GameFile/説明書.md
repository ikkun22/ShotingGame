# BatteryShoting 操作・仕様ガイド

## ゲームの概要

BatteryShotingは、プレイヤー機を操作して敵を撃破し、ボス戦に挑む2Dシューティングゲームです。ステージは1〜3から選択します。画面サイズは800×600です。

ゲーム中は、プレイヤーのHPとスタミナに加えて、PCのバッテリー残量も表示します。バッテリー残量はゲーム開始時のHP・スタミナ設定にも使われます。

## 起動方法

Python 3とpygameが必要です。`GameFile`フォルダーをターミナルで開き、次のコマンドで起動します。

```powershell
python -m pip install -r ..\..\requirements.txt
python main.py
```

ゲーム本体を直接起動する場合は、次のコマンドも使えます。

```powershell
python BatteryShoting.py
```

効果音のMP3ファイルは `GameFile\sounds` フォルダーにあります。ゲームのフォルダーを移動する場合は、`sounds` フォルダーも一緒に移動してください。

効果音ごとの音量は `audio.py` の `SFX_VOLUMES` で調整できます。各値は `0.0`（無音）から `1.0`（最大音量）の範囲で指定します。たとえば、チャージ音を小さくするには `"charge": 0.25` のように変更します。

タイトル・ステージ選択などのメニュー中は `sounds\ゲーム待機中BGM.mp3` をループ再生します。ゲーム開始時はHP・スタミナのカウントアップ中を無音にし、演出後に `sounds\ゲーム中BGM.mp3` をループ再生します。音量は `audio.py` の `MUSIC_VOLUMES` にある `"menu_bgm"` と `"game_bgm"` で個別に調整できます。

バッテリー情報の取得にはWindowsのシステム機能を使います。残量が取得できないPCやWindows以外の環境でもゲームは起動しますが、表示は `--%` となり、HP 5・スタミナ50%の設定で開始します。

## 画面の進み方

1. タイトル画面でSTARTを撃つと、ステージ選択画面に進みます。
2. ステージ1〜3のボタンを撃つと、画面中央にHPとスタミナが0から1ずつ増えて表示され、その後ゲームが始まります。
3. 敵を倒してスコアを獲得し、規定数を倒すとボスが出現します。
4. プレイヤーのHPが0になるとゲームオーバーになります。記録がランキング対象の場合は名前を登録できます。
5. ステージは自動では切り替わりません。次のプレイではタイトル画面からステージを選び直してください。

タイトル画面にはSTART、CUSTOM、SCORE、EXITがあります。メニューのボタンは、プレイヤーから撃った弾を当てて選択します。ゲーム中の弾はスペースキーで発射します。

## 操作方法

### ゲーム中

| 操作 | 入力 | 動作 |
| --- | --- | --- |
| 移動 | 矢印キー | 上下左右に移動します。画面外には出られません。 |
| 射撃 | スペースキーを押して離す | 通常弾を発射します。 |
| チャージ射撃 | スペースキーを1秒以上押して離す | 強力なチャージ弾を発射します。 |
| 回避 | Cキー | 0.5秒間無敵になり、プレイヤーが水色になります。 |
| ポーズ | Enterキー | ポーズメニューを開きます。 |

移動に使えるのは矢印キーです。A/D/W/Sキーには対応していません。

チャージ中にEnterキーを押すと、そのチャージは解除されます。ポーズ中はゲームの進行が止まります。上下キーで「ゲームを続ける」「タイトルにもどる」を選び、Enterキーで決定します。

### メニュー画面

- タイトル、ステージ選択、ランキング、CUSTOM画面では、矢印キーでプレイヤーを動かし、スペースキーで弾を撃ちます。
- ボタンや設定の矢印に弾を当てて選択・変更します。
- SCORE画面では、上部のステージボタンでランキングを切り替え、BACKに弾を当てると戻ります。
- ハイスコアの名前入力では、文字を入力し、Backspaceで1文字消します。Enterキーで登録します。

## 画面表示

- 左上: HPとスタミナのバー。バーの右側に現在値と最大値を数値で表示します。
- ゲーム開始時: HPとスタミナのカウントアップを画面中央に表示します。
- 左下: 現在のスコア。
- 右上: 選択中のステージ。
- ボス出現中の中央下: ボスの現在HP・最大HPと、残量に応じて減るHPバー。
- 右下: 電池アイコンとバッテリー残量。全画面で表示され、約1秒ごとに更新されます。取得できない場合は `--%` と表示されます。

## HP・スタミナ・バッテリー

### ゲーム開始時の値

ゲーム開始時にバッテリー残量を読み取り、最大HPと最大スタミナを決めます。タイトルへ戻って新しいゲームを開始すると、残量を再取得します。

- 最大HP: バッテリー残量を10で割って四捨五入します。最低値は1、最大値は10です。
- 最大スタミナ: バッテリー残量と同じ数値です。
- バッテリー残量が取得できない場合: 最大HPは5、最大スタミナは50%です。

### スタミナ消費と回復

- 通常射撃: 15%消費
- チャージ射撃: 30%消費
- 回避: 10%消費
- スタミナが0のときは射撃・回避できません。残量が消費量に満たない場合も、その行動で0になります。
- 射撃または回避の後、0.5秒経過すると回復が始まり、28ミリ秒ごとに1%回復します。最大値を超えて回復することはありません。

### 被弾と回避

敵や敵弾に当たるとHPが1減り、約1秒間の無敵時間が発生します。無敵中はプレイヤーが点滅します。シールドアイテムを持っている場合は、次の被弾によるHP減少を1回防ぎます。

Cキーの回避は0.5秒間の無敵効果です。被弾後の無敵時間中、または回避中は再発動できません。

## 敵とステージ

敵は倒されるか画面下へ抜けると補充されます。ステージによって出現する敵の種類が変わります。

| 敵 | 動き |
| --- | --- |
| chaser | プレイヤーを追いかけます。 |
| straight | 下方向へまっすぐ進みます。 |
| zigzag | 左右に進行方向を変えながら下降します。 |
| horizontal | 横へ大きく移動しながら下降し、画面端で反転します。 |
| diving | プレイヤーの横位置に寄りながら、速く下降します。 |
| splitter | 横移動しながら下降します。倒すと小型の敵2体に分裂することがあります。 |

- ステージ1: chaser、straight、zigzagが出現します。
- ステージ2: horizontal、diving、splitterが出現します。
- ステージ3: 上記すべての種類が出現します。

## ボス戦

初回は敵を50体倒すとボスが出現します。ボスは画面上部を左右に移動して攻撃し、出現中は通常の敵がいなくなります。ボスのHPは画面中央下のバーで確認できます。

ボスのHPが0になると回復アイテムを落とし、3秒後に通常の敵が再出現します。ボスを倒すたびに、次のボスのHPは2倍になり、次の出現までに必要な撃破数が10増えます。ステージ1ではボスの弾の発射間隔も短くなります。

ボスの攻撃方法はステージごとに異なります。ステージ2では画面端で反射する弾が登場します。ボスに弾を当てると、短い無敵時間が発生して連続ヒットを防ぎます。

## アイテム

通常の敵を倒すと、5%の確率でアイテムが出現します。ボス撃破時には回復アイテムが必ず出現します。アイテムに触れると取得できます。

- シールド（★）: 次に受けるダメージを1回防ぎます。
- 回復（ハート）: HPを1回復します。HPが最大のときは取得されず、その場に残ります。
- 拡散（￥）: 射撃を通常の1方向から3方向、さらに5方向へ強化します。最大強化後に取っても、それ以上は増えません。

## スコアとランキング

敵を倒すとスコアが加算され、ボスに攻撃を当てても加算されます。ランキングはステージ別に上位10件を保存します。

記録が登録対象の場合、ゲームオーバー後に名前入力画面が表示されます。名前は最大4文字で、Enterキーで登録します。ランキング枠が10件未満の場合は登録対象になり、満員の場合は10位と同点以上のスコアが対象です。

保存ファイルは `high_scores.json` です。ランキングを初期化する場合は、`GameFile`フォルダーで次を実行します。

```powershell
python reset_scores.py
```

ステージ1〜3の記録がすべて消去されます。

## CUSTOM設定

タイトル画面のCUSTOMでは、画面上の左右の矢印に弾を当てて値を変更できます。

- 敵の速度: 0.5〜10.0、0.5刻み
- 弾の速度: 2〜20、2刻み
- プレイヤーの速度: 1.0〜10.0、0.5刻み
- 色反転: ボタンを撃つたびにON/OFFを切り替え
- 初期設定に戻す: 速度と色反転を初期値に戻す
- タイトルへ戻る: タイトル画面に戻る

## 主なファイル

- `main.py`: 起動用ファイル
- `BatteryShoting.py`: ゲーム本体
- `Battery.py`: Windowsのバッテリー情報取得と開始時リソース計算
- `audio.py`: 効果音・BGMの読み込み、再生、音量設定
- `settings.py`: 画面・速度・HPなどの設定値
- `stages.py`: ステージ別の敵・ボス設定
- `entities.py`: 敵、弾、アイテムの生成
- `game.py`: 敵や反射弾の移動処理
- `ui.py`: メニュー、ゲージ、バッテリーアイコンなどの描画
- `scores.py`: ステージ別ランキングの保存と読み込み
- `high_scores.json`: ハイスコアの保存データ
- `reset_scores.py`: 実行時にハイスコアの初期化
