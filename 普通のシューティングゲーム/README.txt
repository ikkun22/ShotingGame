2Dシューティングゲーム README

■ 概要
pygameで作成した、プレイヤーが敵を撃つ2Dシューティングゲームです。
敵はプレイヤーに向かって移動し、敵を倒すとスコアが増えます。

■ 必要なもの
・Python
・pygame

pygameがインストールされていない場合は、次のコマンドを実行してください。

pip install pygame

■ 起動方法
コマンドプロンプトまたはPowerShellで、このファイルがあるフォルダを開き、次のコマンドを実行します。

python shotingGame.py

■ 操作方法
・左矢印キー：プレイヤーを左へ移動
・右矢印キー：プレイヤーを右へ移動
・上矢印キー：プレイヤーを上へ移動
・下矢印キー：プレイヤーを下へ移動
・スペースキー：弾を発射
・ウィンドウを閉じる：ゲームを終了

■ ゲームのルール
・プレイヤーは白い三角形で表示されます。
・敵は赤い四角形で表示されます。
・弾は黄色い四角形で表示されます。
・弾を敵に当てると敵を倒せます。
・敵を倒すとスコアが1増えます。
・敵とプレイヤーが衝突すると、プレイヤーのHPが1減ります。
・被弾後は一定時間、無敵状態になります。
・無敵状態の間、プレイヤーは点滅します。
・HPが0になるとプレイヤーが消え、スコアが表示されます。
・ゲームオーバーから5秒後にプログラムが終了します。

■ 敵の追加
敵を1体倒すたびに、画面上部から新しい敵が1体追加されます。
新しい敵は画面上部から出現し、プレイヤーに向かって移動します。

■ 画面サイズ
ゲーム画面は800×600ピクセルです。
